How to Host on GitHub Pages

You can easily host this tracker online for free so all players can access it on their phones or tablets during a game session:

  1. Create a new public repository on GitHub (e.g., echo-engine-tracker).
  2. Save this file locally on your computer with the exact name index.html.
  3. Upload or drag-and-drop your index.html file directly into the root of your new repository and commit the changes.
  4. Go to your repository's **Settings** tab in GitHub.
  5. In the left sidebar, click on **Pages**.
  6. Under **Build and deployment**, set the Branch source to main (or master) and folder to / (root), then click **Save**.
  7. Within 1 minute, GitHub will provide your live web URL where your TCG tracker is hosted!
